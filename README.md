# brasil-sabor-ticket
Para os fans de board games, um jogo baseado nas regras do "Ticket to Ride" com a cara do BRASIL.  

# Brasil sabor Ticket

Jogo de estratégia ferroviária para **2 a 6 jogadores**. Escolha um dos 27 tabuleiros do Brasil, construa trechos entre localidades reais e conecte >

## Baixar a versão 0.9

Abra a seção **Releases** deste repositório. Em **Brasil sabor Ticket v0.9**, baixe o arquivo **`brasil-sabor-ticket-v0.9.zip`** na lista **Assets**>

## Como jogar

**No mesmo computador:** abra `index.html` no navegador e escolha **Local · mesmo computador**. O modo local funciona offline e dispensa o Node.js.

**Em rede local:** o anfitrião precisa do Node.js para iniciar o servidor. Abra `iniciaTrilhosDoCerrado.bat` no Windows ou execute `sh iniciaTrilhos>

## Como vencer

Construa trechos pagando com créditos, vagões e cartas compatíveis. Cada quadrinho construído vale 1 ponto, e o trecho ganha 2 pontos de bônus se to>
